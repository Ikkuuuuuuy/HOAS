# 🌟 Quick Start Guide (For Non-Technical Users)

Follow these simple steps to run the system on your computer.

---

### 🟢 First Time Only (One-time setup):
Make sure **Node.js** is installed on your computer:
👉 Download & install the **LTS version** from [https://nodejs.org/](https://nodejs.org/) *(just click "Next" on all prompts during install)*.

---

### 🚀 How to Run the Website (3 Easy Steps):

#### **Step 1: Open the Project in VS Code**
1. Unzip the downloaded file.
2. Open **VS Code**.
3. Click **File** > **Open Folder...** and choose the extracted folder.

---

#### **Step 2: Open the Command Window**
1. At the very top menu of VS Code, click **Terminal** > **New Terminal** *(a black box will appear at the bottom)*.
2. Copy and paste this command and press <kbd>Enter</kbd>:
   ```bash
   npm run install:all
   ```
   *(Wait 1–2 minutes until it finishes downloading).*

---

#### **Step 3: Start the Website**
1. In the same black box at the bottom, type:
   ```bash
   npm run dev
   ```
   and press <kbd>Enter</kbd>.
2. Open your web browser (Chrome or Edge) and go to:
   👉 **`http://localhost:5173`**

🎉 **That's it! The website will now open and is ready to use.**

---

### 🔑 How to Log In (Easiest Way):
When you open the Login page, you will see colored **1-Click Demo Login** buttons at the bottom. 
Just click any button (e.g. **🏢 Main Admin** or **🏠 Verified Homeowner**) and it will automatically log you in!

---

### 🛑 How to Turn Off the Website:
When you are done:
1. Click on the black box at the bottom of VS Code.
2. Press <kbd>Ctrl</kbd> + <kbd>C</kbd> on your keyboard, then press `Y` and <kbd>Enter</kbd>.
